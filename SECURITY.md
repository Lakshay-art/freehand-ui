# Security Policy

## Supported versions

Security fixes are applied to the latest published release.

## Reporting a vulnerability

Please **do not** open a public issue. Report privately through GitHub:
[Report a vulnerability](https://github.com/Lakshay-art/freehand-ui/security/advisories/new).

Include the affected version, a description, and steps to reproduce. You can
expect an acknowledgement within a few days. Once a fix is released we will
credit you in the advisory unless you prefer otherwise.
